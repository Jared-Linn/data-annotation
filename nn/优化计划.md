# 后续优化方向

> 基于当前最佳模型 BERT (77.24%)，进一步提升准确率的路线图。

---

## 📊 当前基线

| 排名 | 模型 | 准确率 | 参数量 | 训练时间 |
|------|------|--------|--------|---------|
| 🥇 | BERT (全量242K) | **77.24%** | 102M | ~30min (RTX 3080 Ti) |
| 🥈 | CharCNN Deep v3 | 75.67% | 2.1M | 20min |
| 🥉 | CharCNN Original | 75.00% | 142K | 2.5min |

### BERT 分类详情

| 类别 | precision | recall | f1-score | 样本占比 |
|------|-----------|--------|----------|---------|
| S1 日常困扰 | 0.74 | 0.80 | 0.77 | 42.6% |
| S2 心理障碍 | 0.80 | 0.77 | 0.79 | 52.3% |
| S3 紧急危机 | 0.78 | **0.55** ⚠️ | 0.64 | **5.0%** |

**核心瓶颈：S3 召回率仅 55%** — 近一半高危对话被漏检。

---

## 🎯 方向一：提升数据质量（最大杠杆）

**当前最大瓶颈是伪标签质量，不是模型能力。**

| 做法 | 预期提升 | 工作量 |
|------|---------|--------|
| **人工标注 1000 条 S3** | S3 recall 55%→80%，整体 +2~3% | ~1天 |
| **修正明显错误的伪标签**（如 "自杀" 被标成 S1） | +1~2% | ~半天 |
| **扩充关键词库 → 重新生成伪标签** | +0.5~1% | ~2小时 |

**优先处理 S3 紧急危机**（3.1 自杀 / 3.2 自杀计划 / 3.3 自残 / 3.4 伤人 / 3.5 报复）

---

## 🎯 方向二：模型集成

不用选一个模型，让多个模型投票：

```
输入对话
  ├── CharCNN (75%)   ─→  预测结果
  ├── Deep v3 (76%)   ─→  预测结果  ─→  多数投票 → 最终结果
  └── BERT (77%)      ─→  预测结果
```

- **S3 判定规则**：三个模型都同意才判为 S3 → precision 大幅提升
- **预期提升**：+1~2%，尤其 S3 precision
- **工作量**：小，现有模型可直接用

---

## 🎯 方向三：S3 过采样

在训练数据中复制 S3 样本，缓解样本不平衡：

```python
# 将 S3 样本复制 4 倍
train_data = concat([original, s3_samples × 4])
```

- **预期提升**：S3 recall 55%→65%，整体 +0.5~1%
- **与权重实验的区别**：过采样更直接，不会扭曲 loss 函数
- **工作量**：很小，改数据处理代码即可

---

## 🎯 方向四：更长序列 + 更大模型

| 改动 | 预期提升 | 代价 |
|------|---------|------|
| max_len 128 → 256 | +0.3~0.5% | 速度慢 20% |
| BERT-base → BERT-large | +1~2% | 需 24GB+ 显存 |
| 心理咨询领域继续预训练 (Domain-Adaptive Pretraining) | +1~3% | 大量数据和算力 |

---

## 📋 推荐执行顺序

```
优先级 ↓          方向                    预期总提升
──────     ──────────────────    ─────────────────
  1️⃣       集成模型 (投票)            +1~2%
  2️⃣       修正 S3 伪标签             +2~3%
  3️⃣       人工标注小批量 S3          +2~3%
  4️⃣       过采样 + 更长序列           +1~2%
  5️⃣       BERT-large / 领域预训练     +2~4%

  理论天花板：85~90%
```

## 🔧 快速开始

### 集成投票

`nn/ensemble.py` — 加载 CharCNN + BERT，对输入做投票预测

### 伪标签修复

编辑 `nn/pseudo_label.py` 中的关键词词典，增加遗漏的关键词

### 人工标注格式

```json
{
  "question_title": "...",
  "question_content": "...",
  "answers": [{"dialogs": [{"content": "..."}]}],
  "labels": {"label": "3.1"}  // 人工标注
}
```
