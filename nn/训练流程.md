# 心理咨询对话分类 — 神经网络训练流程

## 整体架构

```
原始对话数据 (250,972条)
    │
    ▼
┌─────────────────────────────┐
│ 伪标签生成 (pseudo_label.py) │  ← 关键词匹配，快速生成初始标签
│  30/31 类覆盖               │
└─────────────────────────────┘
    │
    ▼
┌─────────────────────────────┐
│ CharCNN 训练 (char_cnn.py)   │  ← 基线模型，字符级卷积
│  Original: 75.0%            │
│  Deep v3:  75.7% (最佳)     │
└─────────────────────────────┘
    │
    ▼
┌─────────────────────────────┐
│ Self-Training (self_train.py)│  ← 迭代改善标签质量
│  3轮收敛，68.3% → 标签稳定   │
└─────────────────────────────┘
    │
    ▼
┌─────────────────────────────┐
│ 全量标签生成 (generate_labels.py)│ ← Deep v3 对全量预测
│  76% 高置信度, 15% 标签改动  │
└─────────────────────────────┘
    │
    ▼
┌─────────────────────────────┐
│ BERT 微调 (bert_finetune.py) │  ← 预训练语言模型 (需 GPU ≥4GB)
│  本地模型加载，混合精度训练   │
└─────────────────────────────┘
```

## 两阶段分类策略

```
Stage 1: S层级分类 (3类)
  S1 日常困扰 (43%) → 1.学业/2.职场/3.家庭/.../17.其他
  S2 心理障碍 (50%) → 1.抑郁/2.焦虑/3.双相/.../9.其他
  S3 紧急危机 ( 7%) → 1.自杀/2.自杀计划/3.自残/4.伤人/5.报复

Stage 2: 子类分类 (依层级不同 5-17类)
  在已知 S 层级内，进一步细分
```

## 技术要点

### 为什么 CharCNN 比 TF-IDF 好？
TF-IDF 是稀疏特征 + 线性模型，表达能力有限。
CharCNN 用 Embedding + 多尺度卷积，直接在字符序列上学习模式。

### 残差网络为什么有效？
深层网络训练时梯度容易消失。残差连接 (F(x) + x) 让梯度可以直接流过，允许训练更深的网络。

### Self-Training 原理
1. 用带噪标签训练模型 → 模型学到泛化模式
2. 用模型预测，筛选高置信度样本
3. 用模型预测替代原始标签 → 标签更纯净
4. 用新标签重新训练 → 模型更强

### BERT 注意事项
- BERT-base 有 1.02 亿参数，需要 ≥4GB GPU 显存
- 3GB GPU 需用 fp16 + 梯度累积 + 小 batch
- 分类头随机初始化容易在 fp16 下 NaN → 建议先用 fp32 稳定
- 本地模型文件可离线加载 (`nn/bert-model/`)

## 复现步骤

```bash
# 1. 环境安装
conda activate data-annotation

# 2. 生成伪标签（需原始 No*.json 在 data/ 下）
python -m nn.pseudo_label

# 3. 训练基线
python -m nn.char_cnn --subset 50000

# 4. 训练 Deep v3
python -m nn.char_cnn_deep --subset 50000

# 5. Self-Training
python -m nn.self_train --rounds 3

# 6. 生成精炼标签
python -m nn.generate_labels

# 7. BERT 微调（可选，需大显存）
python -m nn.bert_finetune
```
