# 心理咨询数据集标注规范

## 三级标签体系总览

| 层级 | 含义 | 子类数 | 适用边界 |
|------|------|--------|----------|
| **S1** | 烦恼类型（轻度·普通心理困扰） | 17 | 不符合任何 DSM-5 障碍诊断标准，无明确病理症状，仅为短期情绪内耗、现实生活琐事矛盾；不影响核心生活工作功能，可自主调节平复 |
| **S2** | 心理疾病（中度·疑似病理症状） | 9 | 对话文本持续出现病理性情绪、异常思维、刻板行为，完全贴合 DSM-5 对应障碍核心描述；当事人无法自我调节，日常学习、工作、生活功能明显受损。**所有标签均为疑似判定，不做医学确诊** |
| **S3** | SOS 紧急危机（重度·即刻人工干预） | 5 | 出现即时性人身伤害、生命安全高危线索；第一时间终止标准化标注流程，加急推送后台人工值守干预 |

## 二、S2 心理疾病（中度·疑似病理症状）

| 标注 ID | 中文类目名称 | 对应英文名称 | 对应 CCSMHS 核心维度 | 标准化标注备注 |
|---------|-------------|-------------|-------------------|--------------|
| 2.1 | 抑郁障碍（疑似抑郁症） | Depression | C3. 抑郁、C1. 躯体化、C4. 自卑 | 长期持续性深陷低落情绪，情绪严重超出正常波动范畴；习惯性自我否定、回避人群、滋生愧疚自责感；躯体体感疲惫乏力、精力断崖式下滑、时间感知迟缓，对爱好、社交、工作全部丧失愉悦感。**核心关键词：** 情绪持续低迷、兴趣全面减退、专注力涣散、深度自我厌恶、存在消极轻生念头倾向 |

## 四、标注总则

### 4.1 标注基本原则

1. **最高层级优先原则**：当一条文本同时出现多个层级的症状时，优先标注更高层级
   - 只要出现 S3 任何症状，直接标注 S3，忽略其他 S1/S2 症状
   - 同时出现 S1 和 S2 症状时，标注 S2 对应的类目
   - 同一层级出现多个症状时，标注最核心、最严重的那个类目
2. **唯一标签原则**：每条数据仅标注一个最匹配的标签，禁止多标签
3. **疑似不确诊原则**：所有 S2 标签均为疑似判定，不得在标注结果中出现医学确诊表述
4. **不修改原始数据原则**：仅在 `labels` 对象中新增 `label` 字段，不得修改、删除任何原始数据字段

### 4.2 标注流程

1. 快速筛查是否存在 S3 紧急危机症状，如有直接标注对应 S3 标签
2. 如无 S3 症状，对照 DSM-5 标准判断属于 S1（轻度）还是 S2（中度）
3. 根据 CCSMHS 核心维度匹配最具体的类目
4. 核对该类目的标准化标注备注，确认边界无误
5. 输出最终标注结果

### 4.3 易混淆场景判定指南

| 常见场景 | 标注标签 | 判定依据 |
|---------|---------|---------|
| 仅在压力下出现拖延，无其他症状 | **1.7** 现实综合压力情绪 | 对应 CCSMHS C2. 焦虑，属于轻度压力反应 |
| 长期拖延 + 兴趣减退 + 精力下降 | **2.1** 重度抑郁 | 对应 CCSMHS C3. 抑郁 + C4. 自卑，符合抑郁核心症状 |
| 因完美主义强迫思维导致的拖延 | **2.7** 强迫思维行为 | 对应 CCSMHS C8. 强迫 + C2. 焦虑，符合强迫症核心特征 |
| 仅针对特定方面的自我怀疑 | **1.13** 低自尊 | 对应 CCSMHS C4. 自卑，属于轻度自我认知困扰 |
| 全面、持续的自我厌恶 | **2.1** 重度抑郁 | 对应 CCSMHS C3. 抑郁 + C4. 自卑，属于病理性抑郁症状 |
| 因压力导致的短期失眠 | **1.6** 短期睡眠失眠困扰 | 对应 CCSMHS C1. 躯体化 + C2. 焦虑，可通过作息调整改善 |
| 长期失眠 + 早醒 + 情绪低落 | **2.1** 重度抑郁 | 对应 CCSMHS C1. 躯体化 + C3. 抑郁，属于抑郁伴随症状 |
| 因考试/演讲产生的紧张、心跳加速，事后缓解 | **1.7** 现实综合压力情绪 | 对应 CCSMHS C2. 焦虑，有明确诱因，事后缓解 |
| 无明确诱因的突然心悸、濒死感，反复发作 | **2.5** 急性焦虑发作（疑似恐慌症） | 对应 CCSMHS C2. 焦虑 + C1. 躯体化，无明确诱因，反复发作 |
